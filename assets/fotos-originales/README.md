# Fotos originales de Argomedo Performance

Descargadas desde argomedoperformance.cl el 30-09-2026, en la **mayor resolución que tiene el servidor**. Las miniaturas se reemplazaron por el archivo original y las imágenes `-scaled` de WordPress por el original sin reescalar. Se quitaron los duplicados exactos.

- `tema/`: imágenes del tema WordPress (banners de 960×419, logos, íconos, títulos hechos como imagen).
- `biblioteca/AAAA-MM/`: biblioteca de medios de WordPress (fotos subidas entre 2011 y 2013). **Muchas no se publican en ninguna página**: son material reutilizable.
- `_origen.json`: URL de origen de cada archivo.
- Los PDFs de prensa están en `../prensa/`.

**No se descargaron:** capturas de pantalla de ejemplo de WordPress, 2 fondos de pantalla de muestra de Windows (Colinas azules, Invierno) y el placeholder de WooCommerce.
